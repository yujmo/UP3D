Official implementation of **UP3D**, a pseudo-point-enhanced 3D object detection framework.

## Introduction

UP3D improves LiDAR-based 3D object detection by constructing pseudo points from dense depth predictions and using them to complement the original LiDAR observations. The framework is designed to enhance geometric representation while preserving the efficiency of LiDAR-based detectors.

Our method mainly focuses on:
- pseudo-point generation from dense depth maps,
- efficient pseudo-point sampling and utilization,
- pseudo-point-enhanced feature extraction and RoI refinement.

## Installation
### 1.  Prepare for the running environment. 
```
conda create -f tools/pcdet.yml
```

You can either follow the installation steps in [`OpenPCDet`](https://github.com/open-mmlab/OpenPCDet). 

### 2. Prepare for the data.

Please prepare dataset as [voxel-R-CNN](https://github.com/djiajunustc/Voxel-R-CNN) or [OpenPCDet](https://github.com/open-mmlab/OpenPCDet). 
    
Then replace corresponding folders and files with those we provide in [Baidu](https://pan.baidu.com/s/1uq-xD6e5mGUdYm7ROvV6Jw?pwd=swre)(You need unzip the files with .zip extension before replacing). 
    
The depth_dense_twise folder contains dense depth maps, and the depth_pseudo_rgbseguv_twise folder contains pseudo point clouds. 
  
You can download it on Baidu Netdisk or generate it by yourself with depth_dense_twise as follows:

```
cd up3d
python depth_to_lidar.py
```
    
If you want to generate dense depth maps by yourself, it is recommended to use [`TWISE`](https://github.com/imransai/TWISE). The dense depth maps we provide are generated by TWISE. For convenience, you can directly use [`SFD-TWISE`](https://github.com/LittlePey/SFD-TWISE) to generate dense depth maps. Anyway, you should have your dataset as follows:

 ```
    up3d
    ├── data
    │   ├── kitti_sfd_seguv_twise
    │   │   │── ImageSets
    │   │   │── training
    │   │   │   ├──calib & velodyne & label_2 & image_2 & (optional: planes) & depth_dense_twise & depth_pseudo_rgbseguv_twise
    │   │   │── testing
    │   │   │   ├──calib & velodyne & image_2 & depth_dense_twise & depth_pseudo_rgbseguv_twise
    │   │   │── gt_database
    │   │   │── gt_database_pseudo_seguv
    │   │   │── kitti_dbinfos_train_sfd_seguv.pkl
    │   │   │── kitti_infos_test.pkl
    │   │   │── kitti_infos_train.pkl
    │   │   │── kitti_infos_trainval.pkl
    │   │   │── kitti_infos_val.pkl
    ├── pcdet
    ├── tools
```

### 3. Setup.

    ```
    cd up3d
    python setup.py develop
    cd pcdet/ops/iou3d/cuda_op
    python setup.py develop
    cd ../../../..
    ```
